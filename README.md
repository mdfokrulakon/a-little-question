# A Little Question for You ❤️

A romantic, playful, responsive mini-website built with HTML, CSS, and vanilla JavaScript.

## What's included
- Welcome and animated confession
- Interactive compliment cards
- A daydream scene with a gentle orbit illustration
- A playful mock research report / joke cards
- The date invitation, a respectful decline option, and a YES celebration
- Date idea picker, optional audio toggle, progress bar, and replay
- Personalization through `js/config.js`

## Run locally
Open `index.html` in a modern browser, or run `npx serve .` from this folder.

## Personalize
Edit `js/config.js` to set her name, your name, confession, closing message, and optional audio file. Update the copy in `index.html` with genuine details that are actually true. Avoid adding private memories or photographs without considering her privacy.

No frontend framework or build step is required. Google Fonts require internet access; system font fallbacks are provided.
